## 0.2.0 — Production expansion

- Expanded the registry from twelve initial primitives to 51 installable components.
- Added ten composed blocks, including Kira, Mochi, and Atlas specialty workspaces.
- Added complete Component Lab coverage for the published component catalog.
- Added production consumer-fixture, browser, accessibility, and recipe validation coverage.

## 0.1.0 — Foundation

- Introduced Kira, Mochi, and Atlas character systems.
- Added a deterministic, shareable recipe model.
- Added the initial twelve components and the AnUIme authentication block.
- Added the interactive Character Studio.
- Published accessibility and originality standards.

This is an early product release. Component APIs may evolve before 1.0.
