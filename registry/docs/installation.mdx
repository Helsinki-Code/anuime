Install an item with the command shown on its component page:

```sh
npx shadcn@latest add https://anuime.dev/r/anuime-button.json
```

The CLI installs the selected component and its local `anuime-recipe` dependency into the aliases defined by your `components.json`.

## Requirements

- React 19 or a compatible React project
- Tailwind CSS 4
- A shadcn-compatible `components.json`

## Verify the Result

Import the component from your local source tree:

```tsx
import { AnuimeButton } from "@/components/ui/anuime-button";

export function LaunchAction() {
  return <AnuimeButton character="kira">Activate sequence</AnuimeButton>;
}
```

AnUIme has no hosted component runtime. The installed source belongs to your project.
