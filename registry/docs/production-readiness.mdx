AnUIme is production-alpha software until every release gate is complete.

Required before stable release:

- Consumer fixture builds for TanStack Start, Vite React, and Next.js
- Browser coverage for URL restoration, history, clipboard failure, invalid recipes, responsive controls, and installation
- Automated and manual accessibility review with keyboard, VoiceOver, NVDA, zoom, contrast, and reduced motion
- Visual comparison between Component Lab and installed fixture output
- Human cleanup, originality review, and final licensing approval for character artwork
- Error monitoring, performance budgets, security-header verification, dependency scanning, and privacy review
- At least fifteen external alpha users, with seventy percent completing select → customize → install → render without direct assistance

AI Director promotion additionally requires at least ninety percent usable schema-valid proposals, zero disallowed tool execution, and approved latency and cost budgets.
