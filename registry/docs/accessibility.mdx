---
title: Accessibility
description: The interaction and motion quality bar for every AnUIme component.
order: 4
group: Standards
---

AnUIme targets WCAG 2.2 AA and treats accessibility as part of every character system.

Every interactive component must provide:

- Complete keyboard operation
- A visible focus indicator
- Programmatic names, labels, and descriptions
- Semantic status communication that does not rely on color alone
- Sufficient contrast for text and controls
- Reduced-motion behavior
- Responsive layouts that remain usable at zoom

Automated checks are useful but incomplete. Interactive items also require manual keyboard and screen-reader review before a stable release.
