Component Lab renders the real registry components rather than a parallel marketing mockup.

Use it to:

- Select any of the 51 published components and its supported states
- Cast a complete character or mix individual system dimensions
- Test mobile, tablet, and desktop widths
- Force light, dark, system, and reduced-motion behavior
- Undo, redo, reset, and reopen recent local recipes
- Share a validated URL that restores component, state, viewport, zoom, and recipe
- Copy recipe JSON, React usage, or the exact shadcn install command
- Export a PNG preview when the browser supports DOM-to-canvas rendering

Clipboard and image export failures are recoverable and never alter the recipe. Browser back and forward navigation restore URL-owned Studio state.
