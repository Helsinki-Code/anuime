title: Remix Gallery
description: The moderated recipe-sharing model and current read-only gallery.
order: 9
group: Product
---

The first gallery release is a curated, read-only set of approved recipes. Every entry contains a versioned recipe, supported component examples, author attribution, tags, moderation status, and immutable remix provenance.

Public publishing remains feature-gated until authentication, reporting, moderation, account blocking, takedown, privacy export, deletion, and attribution flows are implemented and reviewed.

Gallery entries never contain arbitrary HTML, CSS, JavaScript, or uploaded executable files. Remix opens a new local Component Lab document and records the source attribution in the future persistence layer.
