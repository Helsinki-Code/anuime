AnUIme is an open-source, shadcn-compatible component registry where original anime characters represent complete design systems.

<Callout title="The idea">Choose a character. Shape the vibe. Ship the component.</Callout>

Each character begins with seven board artifacts, translates them into repeatable geometry, and
assigns that geometry to functional component carriers. Components remain accessible, readable
React source that you own after installation.

## Launch Cast

- **Kira // Incisive** — violet mass, cyan hairlines, hard-soft rectangles, and one 114° axis.
- **Mochi // Gracious** — ivory or plum mass, restrained rose state, gold structure, and settling motion.
- **Atlas // Engineered** — cool paper or ink navy, load-bearing frames, cobalt linework, and a 76° beam.

Workhorse components use only abstract motif geometry. Waiting, transition, success, and empty
states may assemble each character's full expressive power.

## Start Here

1. Browse the component catalog.
2. Open the Character Studio to create a deterministic recipe.
3. Install an item with its generated shadcn command.
4. Modify the source inside your project.

AnUIme does not copy existing anime characters, generate arbitrary component implementations, or replace accessibility fundamentals.
