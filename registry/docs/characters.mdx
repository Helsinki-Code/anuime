Kira, Mochi, and Atlas are complete construction systems. Each one maps seven approved board
artifacts to reusable geometry and functional component carriers.

- **Kira // Incisive** — hairpin → chevron, collar → focus ring and stem, fringe → 114° sweep.
- **Mochi // Gracious** — clasp → framed switch, pearl → strung progress, veil → localized focus bloom.
- **Atlas // Engineered** — strap → segmented progress, panel → dock brackets, beam → 76° sweep.

## Two tiers

Workhorse controls remain strictly abstract. Only waiting, transition, success, and empty states may
assemble blade-light, bloom-orbit, or the HUD assembly. Both light and dark variants use identical
geometry; only the authored light behavior changes.

The source boards and their hashes are recorded in `design-spec/manifest.json`. Character identity
does not depend on color alone.
