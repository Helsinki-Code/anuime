Kira, Mochi, and Atlas are original AnUIme characters with different silhouettes, structures, motion grammars, and product use cases.

- **Kira // Neon Ronin** — angular signal geometry for developer tools, gaming, and launches.
- **Mochi // Dream Familiar** — rounded generous systems for communities, creator tools, and onboarding.
- **Atlas // Mecha Architect** — modular engineered structure for dashboards, productivity, and data.

The illustrated concept assets are AI-assisted and recorded in `public/characters/provenance.json`. They require human cleanup, similarity review, and final commercial/open-source usage approval before a stable production release.

Large artwork is delivered as optimized WebP with PNG fallback. Small surfaces use independently authored SVG sigils so character identity does not depend on color alone.
