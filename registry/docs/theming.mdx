A character system is more than a palette. It coordinates five explicit dimensions:

| Dimension | Controls                                                      |
| --------- | ------------------------------------------------------------- |
| Color     | Semantic foregrounds, surfaces, accents, and status treatment |
| Shape     | Radius, clipping, border geometry, and control silhouette     |
| Structure | Density, grouping, hierarchy, and modular composition         |
| Motion    | Duration, easing, choreography, and feedback personality      |
| Density   | Compact, comfortable, or spacious layout rhythm               |

## Kira // Neon Ronin

Use Kira for developer tools, gaming experiences, and launches that need decisive energy. Preserve high contrast and keep glitch-like details decorative.

## Mochi // Dream Familiar

Use Mochi for communities, creator tools, and welcoming onboarding. Friendly does not mean low contrast: text and focus indicators must remain clear.

## Atlas // Mecha Architect

Use Atlas for dashboards, productivity systems, and dense information. Technical framing must support hierarchy rather than become visual noise.

## Reduced Motion

Every decorative transformation must have a reduced-motion fallback. A user preference overrides the selected character's motion personality.
