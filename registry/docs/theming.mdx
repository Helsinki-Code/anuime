A character system is more than a palette. It coordinates five explicit dimensions while preserving
the approved artifact-to-geometry map:

| Dimension | Controls                                                      |
| --------- | ------------------------------------------------------------- |
| Color     | Semantic foregrounds, surfaces, accents, and status treatment |
| Shape     | Radius, clipping, border geometry, and control silhouette     |
| Structure | Density, grouping, hierarchy, and modular composition         |
| Motion    | Duration, easing, choreography, and feedback personality      |
| Density   | Compact, comfortable, or spacious layout rhythm               |

## Kira // Incisive

Kira uses hard-soft rectangles, violet mass, cyan hairlines, and one 114° directional axis. Light
lives in lines; elongated pills and broad cyan decoration are forbidden.

## Mochi // Gracious

Mochi uses measured curves, ivory or warm plum mass, restrained rose state, and champagne structure.
The system is gracious, never sweet; dark mode comes from mauve rather than black.

## Atlas // Engineered

Atlas uses load-bearing rectangles, segmented bands, survey diamonds, cobalt linework, and a
deliberate 76° beam. Ornament without structural function is forbidden.

## Geometry parity

Light and dark variants never introduce different geometry. Daylight draws the approved lines;
darkness may emit them with restraint.

## Reduced Motion

Every decorative transformation must have a reduced-motion fallback. A user preference overrides the selected character's motion personality.
