The v2 recipe mixes color, shape, structure, and motion systems independently while every visual
resolves through the installed canonical theme tokens. Workhorse motion is limited to state
transitions; expressive movement belongs to expressive items.

```ts
import { createAnuimeRecipe } from "@/lib/anuime-recipe";

const recipe = createAnuimeRecipe("kira");
```
